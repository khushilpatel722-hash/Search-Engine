Privacy

Privata is designed as a local application. Your indexed document contents are processed on your own machine and are not intentionally transmitted to third-party search services.

What stays private?

  • No cloud upload
  • No external search API
  • Local indexing
  • Local search
  • User-controlled documents

Document text, search queries and results never leave this computer through Privata.

How indexing works

Privata reads each file, extracts its text, lowercases it, removes punctuation and common words, then records which words appear in which documents. That map is the inverted index. All of it happens inside the Python process running on your computer.

Where files are stored

  • data/documents/ — your documents (copies of uploaded files)
  • data/index/ — the search index and cached text, as JSON and TXT
  • data/app_data/ — search history, as JSON

You can open, back up or delete these folders yourself at any time.

What data leaves the device?

Privata makes no outgoing network requests. It uses no analytics scripts, web fonts, CDNs or APIs, and the server listens on 127.0.0.1, so other computers cannot reach it. Your browser may still talk to the internet for other tabs; that is outside Privata.

Search history

Recent searches and the Analytics page come from a local log. Use Clear history on the Search page to erase it. Your theme and animation choices are saved in your browser's local storage.

Security limitations

  • Files and the index are stored as plain readable files. They are not encrypted; anyone with access to your computer account can read them.
  • Basic protections are included: file-type checks, a 10 MB size limit, safe file names, path-traversal prevention and HTML escaping.
  • This is a learning project, not a hardened security product. Do not expose it to a public network.
