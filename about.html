About Privata

Privata is a lightweight private search engine designed to demonstrate how document indexing, inverted indexes, query processing and relevance ranking work.

Built for

MCA Academic Project

Technologies

PythonFlaskHTMLCSSJavaScript

Concepts

Information RetrievalText ProcessingInverted IndexTF-IDFRankingLocal Search

How a search is answered

  1. QueryYou type words in the browser.
  2. Flask/api/search receives the request on your computer.
  3. Query processorWords are cleaned exactly like the documents were.
  4. Inverted indexEach word is looked up to find candidate documents.
  5. Ranking engineTF-IDF scores are calculated and sorted.
  6. ResultsSnippets are highlighted and sent back with the measured search time.
